# STM32F103C8T6 平衡车工程

这是一个基于 STM32F103C8T6 的两轮平衡车控制器工程，使用 Keil MDK 和 STM32F10x 标准外设库开发。工程包含 MPU6050、双路电机驱动、编码器、电池电压检测、按键、串口调试及 OLED 等驱动或功能模块。

> 当前工程以模块和功能测试代码为主。虽然包含 MPU6050 姿态解算及 PID 算法相关代码，但当前 `main()` 运行的是编码器串口测试，并未组成完整的闭环平衡控制程序。

## 功能模块

- **MPU6050**：通过 I2C 读取加速度计、陀螺仪和温度数据；提供互补滤波姿态角处理。
- **双路电机驱动**：通过 TB6612 控制左右电机方向和 PWM 占空比。
- **双路编码器**：通过外部中断读取左右电机编码器计数。
- **电池电压检测**：通过 ADC 采样电池电压，并用三颗 LED 显示电量状态。
- **按键**：单击切换电机驱动的待机/工作状态。
- **调试串口**：USART2 用于发送编码器及传感器测试数据。
- **基础库**：包含 STM32F10x 标准外设驱动、延时、I2C、SPI、OLED、PID 和定点数学等代码。

## 硬件连接参考

以下引脚根据工程源码中的 GPIO 配置整理。接线前请确认与你的底板、电机驱动模块和传感器模块一致。

| 功能 | STM32 引脚 | 说明 |
| --- | --- | --- |
| MPU6050 I2C SCL | PB8 | I2C1 重映射 |
| MPU6050 I2C SDA | PB9 | I2C1 重映射 |
| 左编码器 A/B 相 | PB14 / PB15 | A 相接外部中断输入 |
| 右编码器 A/B 相 | PB3 / PB4 | A 相接外部中断输入；初始化时禁用 JTAG |
| TB6612 STBY | PA1 | 高电平工作，低电平待机 |
| 左电机方向输入 | PA9 / PA10 | TB6612 AIN1 / AIN2 |
| 左电机 PWM | PA8 | TIM1_CH1 |
| 右电机方向输入 | PB5 / PB7 | TB6612 BIN1 / BIN2 |
| 右电机 PWM | PB6 | TIM4_CH1 |
| 电池电压 ADC | PB0 | ADC1 通道 8 |
| 电量指示 LED | PA4 / PA5 / PA6 | 按电压显示电量或低电压闪烁 |
| 用户按键 | PA11 | 单击切换电机待机/工作状态 |
| USART2 TX / RX | PA2 / PA3 | 当前配置为 921600、8N1 |

连接电机电源时，请确保驱动板与 MCU 共地，并在首次电机测试时架空车轮。不要将电机电源直接接到 MCU 的 GPIO 或电源引脚。

## 编译与下载

1. 安装 Keil MDK-ARM，并准备 STM32F1 系列器件支持包和工程使用的 ARM Compiler 5（工程配置为 ARMCC 5.06 update 7）。
2. 使用 Keil 打开 `Balance_Car.uvprojx`。
3. 选择目标器件 **STM32F103C8**，检查调试器和 Flash 下载器设置。
4. 点击 **Build** 编译工程。
5. 连接开发板和调试器，点击 **Download** 下载程序。

本仓库不包含 Keil 工具链或器件支持包；首次在另一台电脑上打开工程时，可能需要在 Keil 中重新选择本机安装的器件包、调试器和下载器。

## 当前启动流程与测试

当前 [user/main.c](user/main.c) 中调用顺序的第一项是 `Encoder_Test()`。该函数初始化编码器和 USART2 后进入永久循环，每隔约 50 ms 输出左右编码器计数。因此，`Encoder_Test()` 后面的电池、按键和 PWM 初始化代码在当前启动流程中**不可达**，`PWM_Test()` 也不会运行。

如果要测试其他模块，请在 `main()` 中选择对应测试函数，并避免在其前面调用会永久循环的测试。测试入口及实现位于 `test/` 目录，例如：

- `Encoder_Test()`：输出左右编码器计数。
- `MPU6050_Test()` / `MPU6050_EularAngle_Test()`：测试 MPU6050 数据或姿态角。
- `PWM_Test()`：依次测试电机的几个 PWM 占空比；运行前请架空车轮。
- 电池和数学相关测试：参考 `test/` 中对应的源文件。

修改启动测试后，请重新编译并确认所选测试所需的模块已初始化。当前代码中的测试例程主要用于验证外设，不代表完整、经过调试的平衡车控制方案。
