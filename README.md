# STM32F103C8T6 平衡车项目

基于 STM32F103C8T6、STM32 标准外设库和 Keil MDK 的双轮平衡车工程。本仓库上传的是 `D:\MCU\stm32\stm32_project\平衡车\Balance_Car` 版本，保留该版本的工程文件、源代码和车体 3D 模型。

## 项目模块

- **电机调速**：TIM1/TIM4 产生 PWM，TB6612 控制左右电机的方向与输出；`app_motor.c` 使用编码器反馈、电池电压和 `app_pid.c` 完成左右电机转速调节。
- **编码器测速**：读取两侧编码器 A/B 相，计算位置和转速。
- **姿态传感器**：MPU6050 通过 I2C 提供加速度、角速度和姿态角相关接口。
- **电池管理**：ADC 采样电池电压，三颗 LED 显示电量与低压状态。
- **按键与调试**：按键控制 TB6612 待机状态；USART2 输出目标转速及左右轮转速。
- **机械设计**：`平衡车3D模型.STL` 是车体模型文件。

## 蓝牙遥控（9.3 版实现）

项目后续的 9.3 版使用蓝牙模块的**串口透传**功能遥控车辆：蓝牙模块接 USART3（PB10/PB11，9600、8N1）；`app_rc.c` 在串口中断中接收一行命令，主循环解析 `move <转向量> <前进量>`，再调用 `app_control.c` 的接口设置运动目标。USART2 仍用于调试输出。

**版本说明：**本次按要求上传的 MCU 路径版本没有 `app_rc.c`、`app_control.c`，`main.c` 也没有初始化 USART3 或调用遥控处理函数。因此上面记录的是 9.3 版的设计与实现，**不是本仓库当前固件已接入的功能**。若需编译蓝牙遥控固件，应使用 9.3 版完整源码，并核对遥控协议、接线和控制参数。9.3 版接收缓冲区为固定长度，上车前还应检查输入长度和失联停机逻辑。

## 当前源码的运行入口

`user/main.c` 初始化按键、电池、PWM、编码器、电机速度环和 USART2；主循环轮询按键、电池、电机调速及串口输出。目标转速测试值在 `USART2_Proc()` 中生成。MPU6050 的驱动与测试代码虽在工程内，当前 `main.c` 没有运行姿态解算或直立平衡控制。因此此版本可用于验证底层模块和速度环，不能直接视为已完成的蓝牙遥控直立平衡固件。

## 目录与编译

```text
Balance_Car.uvprojx  Keil MDK 工程
user/               主程序和应用模块
my_lib/             通用驱动与算法库
std_periph_driver/  STM32F10x 标准外设库
startup/            启动文件
test/               外设测试代码
平衡车3D模型.STL    车体模型
```

使用 Keil MDK 打开 `Balance_Car.uvprojx`，安装 STM32F1 器件包并检查工程的编译器与下载器配置后编译。首次接电机时架空车轮，确认供电、共地和 TB6612 接线。此仓库未附带工具链，上传时未完成固件编译或实车验证。
